# ACC Immunometabolic Prognostic Framework

Integrated transcriptomic, machine learning, and immunometabolic systems analysis for prognostic stratification in adrenocortical carcinoma (ACC).

## Features
- TCGA and GEO integration
- Random Forest and LASSO prognostic modeling
- ESTIMATE immune analysis
- GSVA metabolic pathway scoring
- Systems-level correlation analysis
- Prognostic risk stratification

## Methods
- R
- GSVA
- ESTIMATE
- Survival analysis
- Machine learning
